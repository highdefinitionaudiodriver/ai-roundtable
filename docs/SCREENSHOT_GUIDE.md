# Screenshot Guide

Recommended public demo flow:

1. Use a low-risk prompt, such as travel planning or study planning.
2. Paste a short AI answer into the source answer field.
3. Click `共有プロンプトをコピー` or `自動議論を開始`.
4. Capture:
   - Desktop full screen
   - Mobile width
   - Timeline after discussion appears

Avoid screenshots that include API keys, private URLs, personal data, or sensitive documents.
